화면을 크게 펼치고,
깔끔하게 승인해요.

개발자가 웹사이트 화면을 올리면 고객은 고칠 곳을 짚어 수정을 요청해요. 수정 전후를 비교한 뒤 최종 버전을 승인할 수 있어요.

로그인 없이 데모 체험하기시작하기검수실 예시 보기
  1. 화면 올리기

    개발자가 화면 사진을 버전별로 올려요.

  2. 수정 요청 남기기

    고객이 사진 위 고칠 자리에 수정 요청을 남겨요.

  3. 버전 승인하기

    지정한 사람이 버전을 승인하면 검수 확인서가 남아요.
